# Codex × DSH 桌面控制台 v1.2.1

给你的 Codex 团队配一个桌面工作台：选择项目、连接自己的 DSH、同步模型设置，再把任务交回 Codex。
团队运行时，项目、Monitor 地址、任务与会话状态都能在一个窗口里查看，网页 Monitor 继续保留详细事件和日志。

## 下载与开始使用

1. 在下方 **Assets** 下载 `codex-dsh-desktop-v1.2.1-windows-x64.zip`。
2. 完整解压，双击 `CodexDshDesktop.exe`；保留同目录的 `_internal` 和 `toolkit` 文件夹。
3. 在“配置与模型”中检测或选择自己的 DSH 配置目录，即包含 `settings.yaml` 的文件夹。
4. 点击“添加项目”选择项目目录，再点击“启动 Monitor”，按提示完成首次准备。
5. 在 Codex 中打开同一个项目，读取项目内的三个 Skill，开始使用 DSH 团队。

桌面界面不需要安装 Python。运行 DSH 项目需要 Node ≥ 22.19.0、可用的 DSH 账号配置，以及首次下载依赖所需的网络。
空白项目目录可以直接使用，不需要先建立 Git 仓库。

`Source code (zip)` 和 `Source code (tar.gz)` 是源码归档；要直接运行桌面程序，请下载上面的完整 ZIP。

## 这次可以做什么

- 从目录选择窗口连接用户自己的 DSH，默认模型跟随用户配置。
- 查看多个项目的 Monitor 地址、任务、DSH 会话，并为项目关联 Codex 对话。
- 为后续任务选择模型，或恢复跟随 DSH 默认设置。
- 查看准备过程的进度、日志和成功／失败反馈。
- 点击“停止后台”清理对应进程及其子进程，释放日志文件占用。连接记录丢失时也可以停止。

**结束 Codex 对话或关闭网页不会自动停止后台。** 删除或移动项目之前，请点击“停止后台”并等待完成；
退出桌面时也可以选择“停止后台并退出”。

DSH 会话信息自动读取；没有历史关联记录的 Codex 对话，可以通过“关联对话”命名。

桌面版号为 **1.2.1**，随附的项目工具包组件保留 **1.1.0** 版本号。旧版发布与历史记录保留。
桌面源码与第三方许可证随包提供，详见包内中文使用说明。
