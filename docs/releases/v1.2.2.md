# Codex × DSH 桌面控制台 v1.2.2

这次让第一次连接 DSH 更直观，也修好了旧配置路径造成的启动失败。

- **先自动找配置。** 点击“自动查找 DSH 配置”，找到一份就记住，多份时由你选择。找不到再手动浏览目录。
- **模型设置有明确提示。** 没连接 Monitor 时可以预览本地模型，并直接启动连接；连接后再应用到后续任务。
- **启动不再被旧路径干扰。** 桌面使用工具包专用运行目录，原有 DSH 配置保持只读，无需修改系统环境变量。
- **支持更多目录名称。** 修复项目路径含方括号时无法启动 Monitor 的问题。
- **统一白色弹窗。** 配置选择、目录浏览和提示窗口保持浅色，系统使用深色模式也能看清。

下载 `codex-dsh-desktop-v1.2.2-windows-x64.zip`，完整解压到新目录，关闭旧桌面程序后打开新的 `CodexDshDesktop.exe`。已有项目可直接添加，无需删除或重新安装项目文件。

项目文件安装可以离线完成；首次启动若缺少 DSH 运行依赖，需要联网下载，已有依赖则跳过。当前 ZIP 不包含完整离线运行依赖，使用前还需要 Node ≥ 22.19.0 和你自己的 DSH 配置。

此版本继续作为预发布版本供试用。原 v1.1.0、v1.2.1 发布保留。
