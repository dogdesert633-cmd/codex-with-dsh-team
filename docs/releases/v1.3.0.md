# Codex × DSH 桌面控制台 v1.3.0

添加项目，安装依赖，再启动团队。每一步都能看见当前状态，不用填写对话 ID，也不用处理 DSH 的内部运行目录。

- 添加项目后自动检查工具包、DSH 依赖和 Node.js；安装、更新与卸载都有独立按钮。
- 每个项目一支团队，角色与 DSH 会话自动显示，重复启动复用当前后台。
- 修复项目脚本误用旧 DSH Home 的问题，桌面和 Codex 直接启动采用相同的目录规则；用户原配置保持只读。
- 已有项目先停止后台，再点击“更新工具包”，即可把启动修复安装到项目中；已有依赖可以继续使用。

下载 `codex-dsh-desktop-v1.3.0-windows-x64.zip`，完整解压后运行 `CodexDshDesktop.exe`。保留同目录的 `_internal` 和 `toolkit`，无需安装 Python。

工具包文件可离线安装；缺少的 DSH 依赖通过 npm 下载。需要 Node.js ≥ 22.19.0，以及你自己的 DSH 配置和凭据。

此版本为预发布，仓库继续保持私有，历史版本保留。
