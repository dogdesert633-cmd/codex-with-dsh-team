# Codex × DSH 桌面控制台 v1.3.1（预发布）

卸载也应该清楚、省心。这一版统一了安装与卸载界面，并补上运行依赖的清理。

- 浅色卸载窗口：先检查、再确认，进度和日志随时可见，完成后有明确提示。
- 新版安装的 DSH 依赖会一起卸载；你修改过或额外添加的文件会保留，并在日志中说明原因。
- 点击“完成”后自动收尾，不再只删掉程序、留下卸载器的安装记录。
- 安装前已有的文件夹保留。桌面“卸载依赖”也使用相同的保护规则。

下载 `codex-dsh-desktop-v1.3.1-windows-x64.zip`，完整解压后运行 `CodexDshDesktop.exe`。已有项目先在桌面控制台更新工具包，再使用项目根目录的新卸载器。

早期版本和手动 npm 安装的依赖没有原始内容记录，不能可靠判断是否被修改，因此默认保留并提示；本版通过桌面安装的依赖会自动登记。原有 DSH 配置、项目代码和任务记录保留。

项目仍处于预发布阶段。
