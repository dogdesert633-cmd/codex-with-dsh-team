# 让 Codex 带个小团队，一起把项目做完。

Codex × DSH Team Toolkit 把团队规则、DSH 调用和桌面控制台放在一起：Codex 负责拆任务、协调和验收，DSH 使用你配置的外部模型，分担适合它的探索、代码实现与审查。

**[下载 Windows 桌面版](https://github.com/dogdesert633-cmd/codex-dsh-team-toolkit/releases/download/v1.3.2/codex-dsh-desktop-v1.3.2-windows-x64.zip)** · [查看项目介绍与界面](https://github.com/dogdesert633-cmd/codex-dsh-team-toolkit/blob/main/README.zh-CN.md) · [English](https://github.com/dogdesert633-cmd/codex-dsh-team-toolkit/blob/main/README.md)

## 安装前先看这里

**每个项目会独立安装一份 DSH 及运行依赖，约 200 MB。** 当前依赖文件内容约 214 MiB；安装记录、npm 缓存和任务数据另占空间。原本的 DSH 安装和配置不会被覆盖。

准备 Windows 10/11、Node.js ≥ 22.19.0，以及已配置好模型与凭据的 DSH。首次准备依赖可能需要联网；桌面程序不需要另装 Python。

## 开始你的第一个项目

1. 下载附件 `codex-dsh-desktop-v1.3.2-windows-x64.zip`，完整解压后运行 `CodexDshDesktop.exe`。
2. 在“配置与模型”点击“自动查找 DSH 配置”，核对供应商和模型。
3. 添加项目，点击“安装工具包与依赖”，完成后启动 Monitor。
4. 回到 Codex，让它读取项目中的三个 Skill，开始分配任务。[复制上手提示](https://github.com/dogdesert633-cmd/codex-dsh-team-toolkit/blob/main/README.zh-CN.md#几步开始)

一个项目，一支团队。角色与会话自动显示；桌面负责连接和设置，网页展示详细进度。你也可以单独使用通用团队 Skill，无需安装 DSH 依赖。

工作结束后请点击“停止后台”。卸载会清理已登记且未修改的工具包与依赖，保留用户修改、新增文件和任务记录；旧版未登记的依赖会提示保留原因。

已有项目使用新桌面包打开后，先停止后台，再点击“更新工具包”。详细技术变更见[更新日志](https://github.com/dogdesert633-cmd/codex-dsh-team-toolkit/blob/main/CHANGELOG.md)。
