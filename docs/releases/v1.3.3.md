# Codex 带队，DSH 分担。

**把宝贵的 Codex 额度留给规划、协调和验收。** 将适合的代码编写、问题排查和代码审查交给 DSH，用你选择的外部模型分担繁琐工作，帮助节省 Codex 额度，让项目继续往前走。

Codex 负责拆任务、带团队、把关结果；DSH 负责执行分配给它的工作。你决定使用哪个供应商和模型，桌面控制台负责项目连接、配置同步与进度展示。外部模型按你的供应商规则计费，实际消耗取决于任务和所选模型。

## 安装前先看这里

**每个项目会独立安装一份 DSH 及运行依赖，约 200 MB。** 当前依赖文件内容约 214 MiB；安装记录、npm 缓存和任务数据另占空间。原本的 DSH 安装和配置不会被覆盖。

准备 Windows 10/11、Node.js ≥ 22.19.0，以及已配置好模型与凭据的 DSH。首次准备依赖可能需要联网；桌面程序不需要另装 Python。

## 开始你的第一个项目

1. 下载附件 `codex-dsh-desktop-v1.3.3-windows-x64.zip`，完整解压后运行 `CodexDshDesktop.exe`。
2. 在“配置与模型”点击“自动查找 DSH 配置”，核对供应商和模型。
3. 添加项目，点击“安装工具包与依赖”，完成后启动 Monitor。
4. 回到 Codex，让它读取项目中的三个 Skill，开始分配任务。[复制上手提示](https://github.com/dogdesert633-cmd/codex-with-dsh-team/blob/main/README.zh-CN.md#几步开始)

一个项目，一支团队。角色与会话自动显示；桌面负责连接和设置，网页展示详细进度。你也可以单独使用通用团队 Skill，无需安装 DSH 依赖。

在 [Monitor 界面展示](https://github.com/dogdesert633-cmd/codex-with-dsh-team/blob/main/README.zh-CN.md#团队正在做什么一眼就能看到) 中，可以看到多个 Agent 同时运行时的任务与对话布局。截图使用演示数据，Monitor 页脚显示作者署名。

工作结束后请点击“停止后台”。卸载会清理已登记且未修改的工具包与依赖，保留用户修改、新增文件和任务记录；旧版未登记的依赖会提示保留原因。

已有项目使用新桌面包打开后，先停止后台，再点击“更新工具包”。详细技术变更见[更新日志](https://github.com/dogdesert633-cmd/codex-with-dsh-team/blob/main/CHANGELOG.md)。
