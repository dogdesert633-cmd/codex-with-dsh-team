# Task capability routing（DSH 边界）

调用方在派发前先判定每项工作的类别。本文件是**DSH 侧的可执行判定表**；通用角色职责与调度
不属于本文件。

## 1. 判定表

| 类别 | 交给 DSH？ | 说明 |
| --- | --- | --- |
| 非视觉代码实现 / 修复 | ✅ 优先 | 含普通不依赖图像的 UI 代码 |
| 只读探索 / 调查 | ✅ | 只定位与取证，不改文件 |
| 代码审查（change-scoped） | ✅ | 只审本轮改动及直接关联 |
| 文本整理 / 结构化改写 | ✅ | — |
| 短命令 / 脚本 / 文件 / 日志 | ✅ | 短/中时长 |
| 正式测试 / 回归裁决 | ❌ | 默认 Codex child 承担 |
| 绘图 / 图像生成 / 图像编辑 | ❌ | 需要图像生成工具 |
| 识图 / OCR / 截图分析 | ❌ | 需要视觉能力 |
| GUI 视觉判断 / 视觉验收 | ❌ | 需要视觉能力 |
| 长运行 / 长等待 / 监控 | ❌ | 留在 Codex 侧 |

**能力不可互换**：图像生成工具 ≠ 视觉能力。缺哪种能力就如实说明缺哪种，不得用纯文本猜测
代替视觉结果，也不得给任务改名绕过本表。

## 2. 各角色的读写边界（DSH 侧）

| 角色 | 可以写 | 不可以写 |
| --- | --- | --- |
| Coder（实现/修复） | 工作包 allowlist 内的文件 | allowlist 之外、他人负责的文件 |
| Explorer（只读探索） | 无 | 任何受版本控制文件 |
| Reviewer（审查） | 无（只读 workspace） | 任何文件；不得顺手修好 |
| Reporter（记录） | 记录类产物 | 生产代码；不得编造机器事实 |

需要越界时先停下来说明，由调用方扩展合同，而非自行扩大范围。

## 3. Coder 自检 ≠ 正式测试

- Coder **可以**在 self-check 中运行**短 smoke**，用于确认自己的改动基本可用。
- 正式验收标准、回归裁决与边界/失败路径验证由**正式 Tester（默认 Codex child）**给出。
- 不得把"Coder 跑过一次"记为验证通过；也不得让 Coder 充当自己改动的最终裁决者。

## 4. 混合任务拆分

| 工作 | 归属 |
| --- | --- |
| 不依赖图像的实现 / 修复 | DSH |
| 自动化行为验证（短） | DSH 可作为 self-check；正式裁决在 Codex 侧 |
| 截图 / 视觉验收 | Codex 侧视觉能力 |
| 生成图表 / 图像资产 | 图像生成工具 |
| 长构建 / 长测试 / 长等待 | Codex 侧执行与监控（DSH 只准备命令与代码） |
